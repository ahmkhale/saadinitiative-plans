# GUI audit — 2026-07-27

## What was wrong

- Course rows rendered before `/api/preview` returned and treated the temporary absence of a resolved model as a confirmed missing catalog course. This produced dozens of false `غير موجود في الدليل` states and opened every manual-fallback editor.
- The post-preview row refresh called `courseBadges` without its required HTML-escape argument, causing `escapeHtml is not a function` and stopping the refresh partway through the page.
- Presentation/font failures discarded the already-resolved academic plan, coupling catalog truth to SVG availability. A missing local font therefore made the editor appear as though catalog resolution itself had failed.
- The editor had weak location cues, an unbounded vertical form, noisy always-visible diagnostics, decorative surfaces, inconsistent radii, and symbolic text controls whose meaning was difficult to scan.
- Footer URLs existed in SVG output, but the browser preview did not give the link group an explicit pointer hit area/cursor contract.

## Structural changes

- Added a persistent university / college / major context trail to the top bar.
- Kept the three working areas visually distinct: navigation, a bounded editing column, and a dedicated preview surface.
- Kept course facts compact by default; detailed facts and dependency rules remain behind each row’s disclosure control.
- Split diagnostics into actionable items and a collapsed informational group.
- Grouped export options separately from the primary save/export actions.
- Replaced symbolic edit/delete/move controls with local outline SVG icons.

## Visual changes

- Replaced slate-tinted/decorative styling with a neutral grayscale and the existing Saad blue `#2b78dd` used only for primary/active/focus states.
- Standardized general control and surface radii at 8px; retained full rounding only for badges and switches.
- Removed the dotted preview background and oversized card shadows; borders and whitespace now carry hierarchy.
- Kept Arabic UI text on IBM Plex Sans Arabic and limited the Latin/system stack to paths, identifiers, and numeric chrome.

## Protected output

No course-card, page, semester, elective, or proposal geometry was changed. The only SVG-output edit adds link interaction metadata (`pointer-events`, `rel`, cursor, and title) to the existing footer link wrappers and transparent hit rectangles.
